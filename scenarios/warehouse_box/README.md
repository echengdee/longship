# Warehouse Box Scenario

> **Status:** Planned reference scenario. No hardware implementation is
> published yet.

This scenario pack will demonstrate how Longship connects a mission, reusable
skills, a target, structured experience, and deterministic evaluation.

The first public version should use synthetic, license-compatible inputs and a
mock target. Planned contents include:

- sample warehouse rules with explicit provenance,
- carry mission contracts and safe-place skill contracts,
- skill-composition examples,
- clear-path and blocked-path cases,
- payload-instability and stale-state failure cases,
- evaluation metrics and promotion gates, and
- small success and failure episodes for replay.

Real customer procedures, order data, facility maps, robot logs, and proprietary
model artifacts do not belong in this pack.

The scenario should become the shortest path for a new contributor to
understand the complete Longship loop without reading an entire robot stack.
